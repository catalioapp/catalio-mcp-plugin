# Changelog

All notable changes to this plugin are documented here.

## 0.1.0 (2026-11-11)

- First release.
- Added the `catalio` MCP server, pointing at Catalio's hosted Streamable HTTP endpoint (`https://catalio.ai/mcp?v=2`).
- Sign-in uses OAuth with your Catalio account through dynamic client registration. There is no API key or client ID to configure.
- Logo: Catalio's official mark (`android-chrome-512x512.png` from catalio.ai), plus the wordmark.
